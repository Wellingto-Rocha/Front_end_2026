O que é um algoritmo?

Um algoritmo é uma sequência finita, lógica e bem definida de instruções criada para realizar uma tarefa específica ou resolver um problema. Na computação, ele funciona como um "passo a passo" que orienta o computador a processar dados ou executar ações. Enquanto o algoritmo é o plano de ação (a receita), a lógica de programação é o raciocínio aplicado para estruturar esses passos de maneira eficiente e correta.

  • Definição: É um conjunto de regras não ambíguas que, ao serem seguidas, levam ao resultado desejado.
  • Analogia: Pode ser comparado a uma receita de bolo: você precisa seguir os ingredientes e as etapas na ordem correta para obter o resultado final.
  • Algoritmo: A lógica da solução (o que deve ser feito).
  • Programa: A tradução desse algoritmo para uma linguagem que o computador entenda.
  • Importância da Lógica: É a base que permite organizar o pensamento, estruturar o código de forma coesa, resolver problemas complexos e garantir que o computador execute as tarefas exatamente como esperado.
Os algoritmos estão presentes em quase tudo na tecnologia atual, desde buscas na internet e sistemas de recomendação em redes sociais até cálculos financeiros complexos.

Fluxogramas

Um algoritmo é uma sequência lógica de passos finitos para resolver um problema. O fluxograma é a representação gráfica desse algoritmo, utilizando formas geométricas padronizadas para visualizar o fluxo de execução. Essa ferramenta facilita a compreensão de processos, identificação de falhas e planejamento do código antes de sua implementação em uma linguagem de programação, tornando o raciocínio mais estruturado e claro. Símbolos Básicos do Fluxograma-> Para construir fluxogramas, utilizam-se símbolos padronizados (norma ANSI, por exemplo) que possuem significados específicos.

  • Oval (Terminador): Indica o início ou o fim do algoritmo.
  • Retângulo (Processo): Representa uma ação, tarefa ou operação a ser executada.
  • Losango (Decisão): Utilizado para tomadas de decisão que exigem uma resposta lógica (ex: Sim/Não ou Verdadeiro/Falso), criando caminhos alternativos.
  • Setas (Linhas de Fluxo): Conectam os símbolos e definem a direção e a ordem em que o processo ocorre.
  • Paralelogramo (Entrada/Saída): Frequentemente usado para representar a leitura de dados (entrada) ou a exibição de resultados (saída).

    • Por que utilizar?

  • Visualização: Transforma lógica textual em um diagrama claro, facilitando a identificação de "gargalos" ou erros na lógica.
  • Padronização: A simbologia universal permite que desenvolvedores de diferentes lugares entendam o fluxo de um sistema.
  • Planejamento: É uma etapa essencial para organizar o pensamento antes de escrever o código real, poupando tempo de depuração futura.

Variáveis

Variáveis são estruturas fundamentais na programação, atuando como "caixas" na memória RAM do computador que armazenam dados temporários durante a execução de um algoritmo. Elas recebem esse nome porque seu conteúdo pode ser alterado conforme a lógica do programa exige. Para utilizá-las corretamente, é necessário definir seu tipo (como inteiro, real, caractere ou lógico), permitindo que o sistema reserve o espaço de memória adequado antes de manipular a informação.

Conceitos Principais

  • O que são: São identificadores (nomes) usados para representar valores que podem mudar ao longo do tempo.
  • Armazenamento: Quando uma variável é declarada, um espaço específico na memória volátil (RAM) é alocado para guardar seu valor enquanto o programa estiver em execução.
  • Tipos de Dados: Cada variável deve ser associada a um tipo, que define o que ela pode armazenar:
    • Inteiro (int): Números sem casas decimais (ex: 10, -5).
    • Real (float, double): Números com casas decimais (ex: 10.5, -3.14).
    • Caractere/Texto (char, string): Letras, palavras ou frases (ex: "Maria", 'A').
    • Lógico (boolean): Valores verdadeiro ou falso (ex: true, false).
  • Variáveis vs. Constantes: Diferente das variáveis, as constantes são identificadores cujo valor, uma vez atribuído, não pode ser alterado durante a execução do programa.
  • Declaração: Na maioria das linguagens e pseudocódigos, é necessário declarar a variável antes de usá-la, informando seu nome e tipo, para que o compilador ou interpretador saiba como tratar aquele dado.
O uso de variáveis torna o código mais intuitivo, flexível e fácil de manter, permitindo que o algoritmo processe informações de forma dinâmica, como realizar cálculos, comparar valores ou controlar fluxos de repetição.

Estruturas condicionais

As estruturas condicionais permitem que um algoritmo tome decisões ao avaliar expressões lógicas (verdadeiro ou falso). Elas direcionam o fluxo de execução, garantindo que blocos específicos de código rodem apenas quando certas condições são atendidas. As principais formas incluem a simples (executa algo apenas se verdadeiro), a composta (executa ações distintas para verdadeiro ou falso) e estruturas de múltipla escolha.

Principais Tipos de Estruturas Condicionais

  • Condicional Simples: Executa um bloco de ações apenas se a condição for verdadeira. Se for falsa, o algoritmo segue para a próxima instrução sem realizar nada.
    • Exemplo: SE (idade >= 18) ENTÃO exibir "Maior de idade".
  • Condicional Composta: Oferece um caminho alternativo. Se a condição for verdadeira, executa o primeiro bloco; caso contrário (SENÃO), executa o segundo bloco.
    • Exemplo: SE (nota >= 7) ENTÃO "Aprovado" SENÃO "Reprovado".
  • Condicionais Aninhadas: Ocorrem quando uma estrutura condicional é colocada dentro de outra, permitindo verificações complexas e hierárquicas.
  • Escolha/Caso (Switch-Case): Utilizada quando há várias opções de valores pontuais para uma variável, tornando o código mais limpo do que múltiplos "se/senão".

Elementos Fundamentais

Para construir essas estruturas, utiliza-se a combinação de:
  • Operadores de Comparação: Como == (igual), != (diferente), > (maior), < (menor), >= (maior ou igual) e <= (menor ou igual).
  • Operadores Lógicos: Permitem combinar várias condições, como E (AND), OU (OR) e NÃO (NOT), possibilitando lógicas mais sofisticadas.
Dominar essas estruturas é essencial, pois elas permitem que o programa "pense" e se comporte de maneira dinâmica frente a diferentes entradas de dados.

Estruturas de repetição

Estruturas de repetição, também chamadas de laços (loops) ou iterações, permitem executar um mesmo bloco de código repetidamente até que uma condição específica seja atendida. Elas são essenciais para automatizar tarefas repetitivas, evitar a redundância de código e processar listas de dados com eficiência. A escolha da estrutura depende de se o número de repetições é conhecido antecipadamente ou se depende de uma condição dinâmica.

Principais Estruturas de Repetição

  • PARA (For): Ideal quando se sabe previamente o número de vezes que o bloco deve ser executado. Utiliza uma variável de controle (contador) que é incrementada ou decrementada automaticamente a cada ciclo.
  • ENQUANTO (While): Verifica uma condição antes de executar o bloco. Se a condição for falsa inicialmente, o bloco nunca será executado. É ideal quando não se sabe quantas repetições serão necessárias.
  • REPITA... ATÉ (Do... While): Verifica a condição após a execução do bloco. Isso garante que o código dentro do laço seja executado pelo menos uma vez, independentemente da condição.

Pontos Importantes

  • Condição de Parada: É fundamental garantir que a condição de parada seja alcançada em algum momento, caso contrário, o programa entrará em um loop infinito, travando a execução.
  • Contadores e Acumuladores: Frequentemente utilizados dentro dos laços, contadores ajudam a controlar o número de repetições, enquanto acumuladores somam ou processam valores ao longo das iterações.
